# VisionGuard Model Weights Directory

This folder stores trained PyTorch model checkpoints and training run artifacts.

## File Conventions
- `best.pt`: The model weights with the highest validation mAP@0.5 during training.
- `last.pt`: The model weights from the final completed epoch.
- `runs/`: Directory automatically generated by Ultralytics YOLO containing:
  - `confusion_matrix.png`
  - `results.png` (Training and Validation loss curves, Precision, Recall, mAP@0.5, mAP@0.5:0.95)
  - `PR_curve.png` (Precision-Recall curve)
  - `F1_curve.png`
  - `args.yaml` (Saved hyperparameter arguments)

## Initializing Weights
If `best.pt` is not present, the inference pipeline falls back to downloading the pretrained `yolov8n.pt` backbone, or training a fresh model using:
```bash
python scripts/train.py --config config.yaml
```
